Setup & help
  1. Install the current Dynamic build.
  2. Allow Open Activity to launch apps in the Pebble phone app.
  3. In Pebble’s Quick Launch settings, assign this same Open Activity app to each shortcut you want to use.

Use one connected watch. This opens Dynamic’s recent selection, including briefly after changing watchfaces.
