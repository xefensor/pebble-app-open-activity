Open Activity

Choose which Dynamic activity each shortcut opens.

Button holds

Primary is the large activity. Secondary is the smaller row.

Button taps

Tap and hold can open different activities on the same button.

Button combinations

Hold both buttons together. Assign combinations in the Pebble phone app’s Quick Launch settings.

Default activity

Used by any shortcut set to Use default.

Setup & help
  1. Install the current Dynamic build.
  2. Allow Open Activity to launch apps in the Pebble phone app.
  3. In Pebble’s Quick Launch settings, assign this same Open Activity app to each shortcut you want to use.

Use one connected watch. This opens Dynamic’s recent selection, including briefly after changing watchfaces.

A missing or expired activity returns to the watchface. It never substitutes Primary for a missing Secondary.
