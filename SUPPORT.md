# Open Activity support

Report problems at [pebble-app-open-activity issues](https://github.com/xefensor/pebble-app-open-activity/issues). Include the app version, watch model and firmware, phone model and Pebble app version, the steps to reproduce, and what you expected. Remove private source text and identifiers from screenshots.

The published 1.0.2 release targets Time 2 and Round 2 with SDK 4.44; Duo is excluded. Source tests, package audits, native emulator runs, simulated phone bridges and physical-device checks have separate scopes. Physical phone/watch and live-provider results are not claimed. See [release readiness](docs/RELEASE-READINESS.md) for the recorded evidence and completed publication status.

Install the current release from [Pebble Store](https://apps.repebble.com/59af0a59f7a34cb09a79bcbe) or download its matching PBW and checksums from [GitHub releases](https://github.com/xefensor/pebble-app-open-activity/releases). Local candidates are not published releases. This project does not require a separate companion app or developer account.
